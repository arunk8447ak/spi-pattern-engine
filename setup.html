📲 V7.2 Telegram Auto – ek baar ka setup

Iske baad Ghaziabad, Gali, Desawar ke 8 jodi apne aap aapke Telegram par aayenge. ~5 minute. GitHub mein login hona chahiye. Koi button na dikhe to browser menu mein "Desktop site" on karo.
1Auto-timer chalu karo (GitHub)

Button dabao. GitHub par file pehle se bhari hui khulegi. Bas hara "Commit changes…" dabao, phir dobara "Commit changes".

1. Timer file banao

Agar file khaali khule: ye file kholo, copy button se poora text copy karo, aur naam .github/workflows/v7_auto.yml rakh kar paste karke commit karo.

2Apna Telegram bot banao

@BotFather ko /newbot bhejo → koi naam (jaise SPI V7) → username jo bot par khatam ho (jaise spi_v7_arun_bot). Wo ek token dega – copy kar lo.

2. @BotFather kholo

Phir BotFather ke message mein apne naye bot ka link (t.me/…) dabao aur Start dabao. Ye zaroori hai.

3Apna chat ID lo

@userinfobot mein Start dabao. Wo Id dikhayega (sirf number) – copy kar lo.

3. @userinfobot kholo
4Dono cheezein GitHub mein chhupa kar daalo

Button dabao aur do baar secret banao:

• Name TELEGRAM_BOT_TOKEN → Secret mein step 2 ka token → Add secret
• Phir dobara button: Name TELEGRAM_CHAT_ID → Secret mein step 3 ka Id → Add secret

4. Naya secret banao

Secrets kisi ko dikhte nahi, public files mein nahi jaate.

5Test karo

Run workflow dabao (mode test rehne do) → hara Run workflow. 1–2 minute mein Telegram par "✅ V7.2 Auto chal raha hai!" aana chahiye.

5. Test run

Poori jaankari: automation/README.md. Ye V7.2 ke pichhle data par based hai; jeet ki guarantee nahi.
