## 🧠 SAGE V5 Architecture

SAGE (Smart Adaptive Guidance Engine) evaluates 32 out-of-sample validated rules to determine daily strategy selection:
1. **Trigger Check:** If a validated rule fires today -> Switches to **SAGE Mode** (10-number cluster, 45% Top-10 accuracy).
2. **Fallback:** If no rule fires -> Seamlessly falls back to **V3 Baseline** (8-number cluster).
